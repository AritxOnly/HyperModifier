# 1.5.2 静态性能审查与验证

2026-10-17；发布比较基准为正式 `v1.5.1`（`1fff270`），源码快照为当前工作区，范围见 [清单](RELEASE_1.5.2_WORKSPACE_INVENTORY.md)。检查启动、主线程、帧回调、缓存生命周期、IPC、锁、渲染及后台工作。此为重点路径的静态检查和主机回归，不是逐行形式验证；本轮没有真机性能/功耗对照或微基准。

| 变更 | 检查结果与验证边界 |
| --- | --- |
| 通知中心超级岛背景移除 | 删除 8 个 apply/clear Hook，移除通知弱目标表、第二次查询和通知配置刷新。展开背景仍使用单目标表、数组复用及合并排队。旧备份退休键仅在导入时跳过，不进入高频路径。 |
| 桌面 ABI 与来源校验 | 来源逐接口解析、契约/helper/live 代码验证在既有后台安装阶段进行；原文件缓存总上限 8MiB，完成后释放。主机 ASan/UBSan 验证真包和拒绝分支。前台兼容状态为用户请求，带超时、长度和对端 UID 校验，不轮询。 |
| 本地组件目录 | 独立作用域只安装目录相关功能；读取本地提供方、元数据及预览仍有 IPC/解析成本，在目录加载事件执行。工作线程 10 秒空闲回收、弱 Context 和代际/协程有效性检查。大量提供方首次加载和取消仍需真机分配/延迟验证。 |
| HMC | APK/DEX 解析移至一次性后台准备，以生命周期代际区分尚未就绪与永久不兼容；完成/失败后不重复扫描。绑定与 View 相关操作回到 UI 线程。真实上游版本静态验证记录见 HYPERMUSICCOVER_EXTENSIONS.md，本轮没有重新取得并验证所有官方 APK。 |
| 通话材质 | 主界面进程使用专用适配，不安装通用资源 Hook/桌面桥接。默认位图路径无额外 BitmapPass/ThreadLocal 写入；相关设置改变合并刷新，原生生成完成事件触发恢复，不使用生成状态轮询。启用时的位图重生成、RenderScript/绘制是实际成本，需真机测量。 |
| 抖音/共用底栏 | 抖音仅主进程安装；设置变化比较相关键。NativeGpuBackdrop 复用既有 RenderNode，几何未变不重复录制；同窗口不由 source OnDraw 反复 invalidate 自身，停用/销毁移除监听、任务及 display list。Texture 帧更新仍会触发玻璃消费端绘制。SurfaceView 回退截取限制宽度约 256px、66ms 调度间隔、单次在途与有限重试，缺源后停止连续发现；这是潜在 GPU/IPC 成本，不能称零功耗。迟建视频锚点按已知层级限额解析，无新增每帧树扫描。 |
| Spotify | 共用底栏生命周期与捕获路径发生变化，Capsule 组件同步有修改；应用页面、键盘及前后台共存需设备回归。不能将抖音的历史用户反馈外推到所有应用。 |
| 锁屏指纹 | 缓存认证归属和息屏字段，只在锁屏认证隐藏，非锁屏直接退出；息屏保留仍受认证归属限制，无新渲染层/IPC/轮询。支付/应用锁及密码页切换待真机回归。 |
| 状态栏显秒 | 三个 MiuiClock 生命周期/更新 Hook，共用整秒 Handler 任务；仅亮屏且附着可见、非演示时持续调度，屏幕关闭/停用/隐藏后取消，关闭恢复原生 updateTime。缓存字段、格式器、Date 与格式缓冲，弱引用目标；设置仅按启用状态变化刷新。每秒仍有字符串、文字绘制/布局成本，未测功耗。 |
| 捐赠页 | 页面按需读取资源，图片在 IO 线程缩小解码，保存复制原图；只有用户点击才写 MediaStore。没有后台定时工作。 |
