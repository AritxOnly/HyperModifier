# 模块入口与配置备份

入口：关于 → 模块设置。

- 隐藏桌面图标只禁用 `.LauncherAlias`，主 SettingsActivity 与 LSPosed 设置入口保持可用。显示图标恢复 alias 默认状态；系统设置入口无需重启作用域。
- 系统拨号器输入 `*#*#4976#*#*` 打开模块。支持系统新旧 Secret Code 广播，具体拨号器是否发送广播需真机验证。
- 备份通过系统文件选择器导出版本化 JSON，包含全部可移植运行配置及内嵌自定义图片。不包含 Launcher alias 状态、诊断令牌、作用域、重试计数和下载图片缓存。
- 恢复先检查格式、版本、字段、类型和 4 MiB 大小限制，确认后一次提交。仅覆盖文件中的键，其他本地设置保留。未知键/版本拒绝，不进行部分写入。恢复后同步页面状态；部分功能仍需重启对应作用域。

## 性能检查范围

静态检查：未增加电话/桌面进程 Hook、作用域、轮询、服务、绘制或 GPU 效果。PackageManager 调用仅发生在打开页面和点击显隐时。备份 JSON 处理、文件 IO、恢复提交在 IO dispatcher 上；恢复跳过未改变字段，无变化时不提交、不通知，有变化时仅一次提交、一次合并远端同步及一次 Provider 通知。同步复用现有 SettingsSyncQueue。

单元测试覆盖类型往返、内嵌文本/图片、部分旧备份、错误版本/来源/字段/类型、整数与浮点溢出、损坏 JSON 和文件大小限制。

## 真机验收

- 新装和覆盖安装只有一个桌面图标；已有桌面快捷方式的 alias 迁移行为。
- 确认框取消不隐藏；隐藏后拨号码和 LSPosed 均能打开；恢复显示并重启手机仍保持选择。
- 导出→修改多个配置→恢复，验证当前主页和详情页均刷新，不被旧页面状态覆盖。
- 自定义图片、每应用规则、布局 XML 的往返；恢复后作用域即时刷新与重启生效路径。
- 取消文件选择、取消恢复确认、损坏/超大/不匹配文件、文档提供方不可写时，不修改配置。
- 未连接真机时不宣称拨号兼容性、帧率或耗电已验证。
